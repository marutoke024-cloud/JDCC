# DC運用ガイド 読本

データセンター運用の学習アプリ(PWA)。2つのカテゴリを収録しています。

- **JDCC ガイドブック** — 「データセンター運用ガイドブック(第2版)」全13章・約58万字を毎日少しずつ読み進める
- **CDFOM 研修** — 資格試験の個人ノート(全11モジュール)。頻出箇所を音声で聞き流して復習する

コンセプトは「**静かな紙面 × 進捗だけが色を持つ**」。装飾を抑えた明朝の紙面に、藍色(`#2C4A63`)のアクセント1色だけで進捗・マーカー・用語・読了を表現します。

## 機能

- **章カード一覧** — 未読 / 学習中(左端バー) / 読了(淡いティント + チェック)の3状態と進捗率
- **1日の学習範囲の自動提案** — 目標日数 or 1日あたり文字数から、今日読む範囲(章・節)を逆算して提示。ノルマ達成度はプログレスバーで静かにフィードバック
- **しおり / 前回の続きから** — 最後に読んだ段落に加え、閉じたときのスクロール位置も記録。ホームの「前回の続きから」でその場所へ戻れる(段落を基準に保存するため、文字サイズや幅を変えてもずれない)
- **用語集 + ホバー解説** — 160語を収録。本文中の用語に点線下線を引き、ホバー(スマホはタップでボトムシート)で解説。横断検索と登場箇所ジャンプつき
- **読み上げ(TTS)** — 本文を音声で読み上げ。女性の声を優先して選び、用語集の読みで専門用語を補正する。読み上げ中の段落はハイライトして自動追従し、しおりも更新される
- **マーカー** — 本文選択でハイライト。`{chapterId, paragraphId, startOffset, endOffset}` を別ストアに保存し表示時に重ねる。一覧ページから該当段落へジャンプ
- **余白ノート** — 段落ホバーで現れるペンから、余白にメモ(広幅画面では本文右の余白にインライン展開、スマホはボトムシート)
- **メモパッド** — トップバーから開閉できる右側の常設メモ欄。章をまたいで使え、入力は自動保存される
- **章末サマリー** — 各章の本文を読解して作成した要点を箇条書きで表示。**原文外バッジ**つきの別枠で原文と明確に区別し、自分の言葉に書き換えることもできる(元に戻すことも可)
- **PWA** — オフラインで全章閲覧可、ホーム画面追加対応(iOS は初回に案内)、ダークモード対応

## CDFOM 研修(試験対策カテゴリ)

Obsidianで書いた研修ノートを取り込んだカテゴリです。トップバーの学帽アイコン、またはホームのバナーから入れます。

- **モジュール1〜11** と **試験 頻出箇所一覧** を読めます。ノート内の `==ハイライト==` は試験の頻出箇所として本文中で強調表示されます
- **頻出箇所の聞き流し** — ハイライト箇所(重複を除いて151項目)だけを続けて読み上げます。**繰り返し再生**にすれば何周でも流し続けるので、走りながら耳で復習できます
  - 範囲は「すべて / 頻出一覧のみ(89件) / モジュールのみ(62件)」から選択
  - 項目ごとの**間**(0〜3秒)を調整でき、既定は1秒
  - 読み上げ中の項目はハイライトされ、画面を見れば現在地が分かります
  - 一覧の項目をタップすると、そこから再生を始められます
- 読み上げには見出しが前置きされるため(「サービスカタログ。提供可能な標準サービスは…」)、耳だけでも文脈をつかめます

ノートの変換は `tools/build-cdfom.mjs` が行い、`data/cdfom.json` を生成します。元のObsidianノートはリポジトリに含めていません。

```bash
node tools/build-cdfom.mjs <ノートのディレクトリ>
```

## 原文データ

`data/chapters.json` に全13章・584,153字の原文を収録しています。形式は以下のとおりです。

```json
[
  {
    "chapter": 1,
    "title": "第1章 概要",
    "start_index": 33170,
    "paragraphs": ["段落テキスト", "..."],
    "char_count": 10297
  }
]
```

このうち索引・図表目次・執筆者名簿・奥付(第13章末尾)は付録として学習対象から除外され、**学習対象は 520,445字**になります。

### 原文の不変性(最重要の設計制約)

- `chapters.json` は**読み取り専用**。アプリに書き込み経路は存在しません
- 進捗・しおり・マーカー・メモ・章末まとめ・用語集は、すべて原文とは**別のデータストア**(IndexedDB / Firestore)に段落ID(`ch02-p0134` 形式)で紐づけて保存されます
- 句点改行・スペース詰め・見出し切り出しなどの表示整形(`js/format.js`)は**純粋関数**で、表示時にのみ適用されます

## 表示整形ルール(js/format.js)

PDF由来の原文には行折り返しや語中スペースの乱れがあるため、**表示時のみ**以下を適用します(原文データは変更しません)。

1. **段落の復元** — 原文の段落の約66%は文の途中で分断されている(「その安定的/継」+「続的稼働及び…」)。句点で終わらない段落を次と連結して文を復元する
2. 「。」の直後で改行(1文1行)
3. 全角文字に挟まれた単独の半角スペースを除去(英数字間は保持)。表・箇条書き行はスペースが列区切りなので詰めない
4. 段落先頭に連結した節見出し(`1.1.1 データセンターとは 個人的な…`)を切り出して見出し要素に
5. `1.` = h2 / `1.1` = h3 / `1.1.1` = h4 として目次を生成(全13章で291見出しを抽出)
6. 章冒頭に混ざる「第N章 タイトル」を本文から除去
7. 第13章末尾の索引・図表目次・執筆者名簿・奥付は付録(学習対象外)として分離

整形はすべて純粋関数として実装され、原文文字列を入力に表示用データを返します。

## レイアウト

左右のパネルは、本文の幅を削らずに置ける広さになってから現れます。

| 画面幅 | 構成 |
|---|---|
| 〜767px | 本文のみ + ボトムナビ |
| 768〜1279px | 本文のみ(章一覧・目次はドロワー) |
| 1280〜1499px | 章一覧 + 本文(目次はドロワー) |
| 1500px〜 | 3カラム |

メモパッドを開くと本文が左へ寄り、3カラム時は右パネルが畳まれて本文幅を保ちます。

### 本文の幅と文字の大きさ

どちらも学習設定から3段階で切り替えられます。互いに独立しており、選ぶとその場で反映され、次回以降も保持されます。

**本文の幅**(既定は「最大」)

| 設定 | 上限 | 目安 |
|---|---|---|
| 標準 | 980px | 1行 約60文字。読みやすさ優先 |
| 広い | 1320px | 1行 約80文字 |
| 最大 | 1800px | 画面の横幅をほぼ使い切る。ワイドモニター向け |

**文字の大きさ**(既定は「標準」)

| 設定 | 本文 | 目安 |
|---|---|---|
| 小 | 15px | 1画面に多くを収めたいとき |
| 標準 | 16.5px | 長く読んでも疲れにくい |
| 大 | 18.5px | ゆったり読みたいとき |

見出しは本文サイズに連動して拡大縮小します。スマホでは画面幅に合わせて1px控えめに描画されます。

章の扉絵は本文が広くても引き伸ばされないよう、900px を上限に中央へ置きます。

## 読み上げ(TTS)

トップバーのスピーカーアイコンから、表示中の章を読み上げます。ブラウザ標準の Web Speech API を使うため、追加のサーバーもAPIキーも不要です。

- **声を選べる** — 端末が持つ日本語音声を一覧から選択でき、女性音声には「女性」タグが付きます。既定は Microsoft Sayaka(なければ Kyoko / Nanami / Ayumi などをスコア順に選択)
- **お気に入りとして保存** — 学習設定に「読み上げの声と速度」を用意。試聴しながら選べて、保存した組み合わせは次回以降そのまま使われます(調整不要)
- **専門用語の読み補正** — 用語集の `reading` を使い、「UPS → ユーピーエス」「受変電設備 → じゅへんでんせつび」のように置換してから発話します。用語を足すほど読みの精度が上がります
- **開始のラグを抑える** — 起動時にアイドル時間で音声リストを解決し、アイコンにポインタが乗った時点で音声エンジンを温めます(無音の発話を1回通す)。押した瞬間から声が出ます
- **表はスキップ** — 列がスペース区切りの表データは音読に向かないため読み飛ばします
- **画面と連動** — 読み上げ中の段落を淡くハイライトして自動追従し、しおりも更新されます
- **連続再生** — 章やモジュールを読み終えると、自動で次へ送って読み続けます。バーの「連続」で切り替えられ、最後まで到達すると停止します
- **CDFOMのモジュールも読み上げ対象** — モジュール本文にある「このモジュールを読み上げ」から開始でき、モジュール1→11へ順に送られます
- 速度の既定は 1.45倍。0.6〜2.0倍で調整でき、段落単位の前後移動ができます
- **用語ポップアップ** — タッチ端末では `pointerup` で拾うため、タップの取りこぼしがありません。画面のどこかに触れる/スクロール/Escで閉じます

### 制約

| 環境 | 動作 |
|---|---|
| Windows / macOS のブラウザ | 問題なく動作 |
| Android | 動作(Google日本語音声が高品質) |
| iOS Safari | 画面ロックやタブ切り替えで**停止します**(OSの仕様) |

音声そのものはOSが持つエンジンに依存するため、品質は環境によって差があります。

## 端末間同期(任意)

しおり・マーカー・メモ・進捗・まとめは、Firebase を設定すると端末間で同期できます。

1. Firebase プロジェクトを作成し、匿名認証と Cloud Firestore を有効化
2. `data/firebase-config.json` に Web アプリ設定を配置:

```json
{ "apiKey": "...", "authDomain": "...", "projectId": "..." }
```

ファイルがなければ完全にローカル(IndexedDB)のみで動作します。

## 開発

ビルド不要の静的アプリです。

```bash
python3 -m http.server 8000   # ルートで起動して http://localhost:8000
node tools/gen-icons.mjs      # PWAアイコンの再生成(依存なし)
```
