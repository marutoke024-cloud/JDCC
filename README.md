# DC運用ガイド 読本

JDCC「データセンター運用ガイドブック(第2版)」全13章・約58万字を、**毎日少しずつ読み進める**ための PWA 学習アプリ。

コンセプトは「**静かな紙面 × 進捗だけが色を持つ**」。装飾を抑えた明朝の紙面に、藍色(`#2C4A63`)のアクセント1色だけで進捗・マーカー・用語・読了を表現します。

## 機能

- **章カード一覧** — 未読 / 学習中(左端バー) / 読了(淡いティント + チェック)の3状態と進捗率
- **1日の学習範囲の自動提案** — 目標日数 or 1日あたり文字数から、今日読む範囲(章・節)を逆算して提示。ノルマ達成度はプログレスバーで静かにフィードバック
- **しおり(自動)** — 最後に読んだ段落を自動保存し、「続きから読む」導線を表示
- **用語集 + ホバー解説** — 本文中の用語に点線下線。ホバー(スマホはタップでボトムシート)で解説。横断検索と登場箇所ジャンプつき
- **マーカー** — 本文選択でハイライト。`{chapterId, paragraphId, startOffset, endOffset}` を別ストアに保存し表示時に重ねる。一覧ページから該当段落へジャンプ
- **余白ノート** — 段落ホバーで現れるペンから、余白にメモ(広幅画面では本文右の余白にインライン展開、スマホはボトムシート)
- **メモパッド** — トップバーから開閉できる右側の常設メモ欄。章をまたいで使え、入力は自動保存される
- **章末サマリー** — 各章の本文を読解して作成した要点を箇条書きで表示。**原文外バッジ**つきの別枠で原文と明確に区別し、自分の言葉に書き換えることもできる(元に戻すことも可)
- **PWA** — オフラインで全章閲覧可、ホーム画面追加対応(iOS は初回に案内)、ダークモード対応

## 原文データ

`data/chapters.json` に全13章・584,153字の原文を収録しています。形式は以下のとおりです。

```json
[
  {
    "chapter": 1,
    "title": "第1章 概要",
    "start_index": 33170,
    "paragraphs": ["段落テキスト", "..."],
    "char_count": 10297
  }
]
```

このうち索引・図表目次・執筆者名簿・奥付(第13章末尾)は付録として学習対象から除外され、**学習対象は 520,445字**になります。

### 原文の不変性(最重要の設計制約)

- `chapters.json` は**読み取り専用**。アプリに書き込み経路は存在しません
- 進捗・しおり・マーカー・メモ・章末まとめ・用語集は、すべて原文とは**別のデータストア**(IndexedDB / Firestore)に段落ID(`ch02-p0134` 形式)で紐づけて保存されます
- 句点改行・スペース詰め・見出し切り出しなどの表示整形(`js/format.js`)は**純粋関数**で、表示時にのみ適用されます

## 表示整形ルール(js/format.js)

PDF由来の原文には行折り返しや語中スペースの乱れがあるため、**表示時のみ**以下を適用します(原文データは変更しません)。

1. **段落の復元** — 原文の段落の約66%は文の途中で分断されている(「その安定的/継」+「続的稼働及び…」)。句点で終わらない段落を次と連結して文を復元する
2. 「。」の直後で改行(1文1行)
3. 全角文字に挟まれた単独の半角スペースを除去(英数字間は保持)。表・箇条書き行はスペースが列区切りなので詰めない
4. 段落先頭に連結した節見出し(`1.1.1 データセンターとは 個人的な…`)を切り出して見出し要素に
5. `1.` = h2 / `1.1` = h3 / `1.1.1` = h4 として目次を生成(全13章で291見出しを抽出)
6. 章冒頭に混ざる「第N章 タイトル」を本文から除去
7. 第13章末尾の索引・図表目次・執筆者名簿・奥付は付録(学習対象外)として分離

整形はすべて純粋関数として実装され、原文文字列を入力に表示用データを返します。

## レイアウト

左右のパネルは、本文の幅を削らずに置ける広さになってから現れます。

| 画面幅 | 構成 |
|---|---|
| 〜767px | 本文のみ + ボトムナビ |
| 768〜1279px | 本文のみ(章一覧・目次はドロワー) |
| 1280〜1499px | 章一覧 + 本文(目次はドロワー) |
| 1500px〜 | 3カラム |

メモパッドを開くと本文が左へ寄り、3カラム時は右パネルが畳まれて本文幅を保ちます。

### 本文の幅と文字の大きさ

どちらも学習設定から3段階で切り替えられます。互いに独立しており、選ぶとその場で反映され、次回以降も保持されます。

**本文の幅**(既定は「最大」)

| 設定 | 上限 | 目安 |
|---|---|---|
| 標準 | 980px | 1行 約60文字。読みやすさ優先 |
| 広い | 1320px | 1行 約80文字 |
| 最大 | 1800px | 画面の横幅をほぼ使い切る。ワイドモニター向け |

**文字の大きさ**(既定は「標準」)

| 設定 | 本文 | 目安 |
|---|---|---|
| 小 | 15px | 1画面に多くを収めたいとき |
| 標準 | 16.5px | 長く読んでも疲れにくい |
| 大 | 18.5px | ゆったり読みたいとき |

見出しは本文サイズに連動して拡大縮小します。スマホでは画面幅に合わせて1px控えめに描画されます。

章の扉絵は本文が広くても引き伸ばされないよう、900px を上限に中央へ置きます。

## 端末間同期(任意)

しおり・マーカー・メモ・進捗・まとめは、Firebase を設定すると端末間で同期できます。

1. Firebase プロジェクトを作成し、匿名認証と Cloud Firestore を有効化
2. `data/firebase-config.json` に Web アプリ設定を配置:

```json
{ "apiKey": "...", "authDomain": "...", "projectId": "..." }
```

ファイルがなければ完全にローカル(IndexedDB)のみで動作します。

## 開発

ビルド不要の静的アプリです。

```bash
python3 -m http.server 8000   # ルートで起動して http://localhost:8000
node tools/gen-icons.mjs      # PWAアイコンの再生成(依存なし)
```

## 構成

```
index.html          アプリシェル
css/app.css         デザイントークン + 全スタイル(ライト/ダーク)
js/format.js        表示整形(純粋関数・原文不変)
js/state.js         共有状態・進捗/ノルマ計算
js/db.js            IndexedDB ストア(progress/bookmark/highlights/notes/summaries)
js/reader.js        読書ビュー(マーカー/ノート/用語/読了トラッキング)
js/app.js           ルーター・ホーム・一覧ページ・設定
js/sync.js          Firebase 同期(任意)
data/chapters.json  原文(読み取り専用)
data/glossary.json  用語辞書
data/summaries.json 章末サマリー(本文の読解による要約・原文外)
sw.js               Service Worker(オフライン対応)
manifest.json       PWA マニフェスト
```
